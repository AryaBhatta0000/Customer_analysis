🛍️ Customer Shopping Behavior Analysis
📌 Overview

This project analyzes customer shopping patterns to support data-driven business decisions. It includes:

1. Data cleaning and feature engineering in Python
2. Exploratory Data Analysis (EDA)
3. Business insights extraction using SQL in PostgreSQL
4. Interactive visualization using Power BI
5. Final insights summarized in a presentation

🗂️ Dataset
Records: 3,900 purchase transactions
Features: 18 columns
Missing Values: 37 entries in Review Rating (handled during cleaning)

Key Data Attributes:
1. Customer demographics (age, gender, location, subscription status)
2. Purchase details (product, category, price, season, size, shipping type)
3. Behavioral traits (discount usage, purchase frequency, review rating)

🛠️ Tools Used

Python – data cleaning, analysis (pandas, numpy, matplotlib, seaborn)
PostgreSQL – structured query analysis
Power BI – dashboard creation and visual analytics
PowerPoint – final presentation & storytelling
Git & GitHub – version control and documentation

🔧 Project Steps
1. Data Cleaning (Python)
Loaded and inspected raw dataset
Standardized column names for readability
Imputed missing ratings using median by product category
Engineered new features like:
Age Group
Purchase Frequency

2. Exploratory Data Analysis
Summary statistics & distribution plots
Purchase behavior analysis across:
Age groups
Gender
Subscription status
Discount & shipping cost comparisons

3. SQL Analysis (PostgreSQL)
Revenue breakdown by gender and age
Identification of top-rated and most-purchased products
Customer segmentation:
1.New
2.Returning
3.Loyal
Subscription vs. non-subscription spending patterns
Shipping method vs. purchase value comparison

4. Dashboard Development (Power BI)
Visualized:
1.Revenue performance
2.Customer segments
3.Discount usage patterns
4.Product category performance
5.Added slicers for interactive filtering (age, category, shipping type, etc.)

5. Presentation
Highlighted business insights and strategic recommendations
📊 Dashboard Highlights
The Power BI dashboard allows users to explore:
Top-performing products & categories
Spending trends by demographic groups
Subscription benefit insights
Impact of discounts and shipping choices on spending behavior

✅ Key Results & Insights
Male customers generated higher total revenue than female customers
Young Adults emerged as the highest-value age group
Subscribers purchased more consistently, though non-subscribers contributed more revenue due to volume
Express shipping orders typically had higher purchase values
Products like Hats and Sneakers were heavily discount-driven, suggesting price sensitivity
